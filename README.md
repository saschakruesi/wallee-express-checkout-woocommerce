# wallee Express Checkout

WooCommerce plugin that adds express checkout buttons, powered by wallee.

The plugin lives in `plugin/wallee-express-checkout/`. PHP 7.4+ is required.

## Development

No local PHP is needed; everything runs through Docker.

- `bin/test [phpunit args]` runs the PHPUnit suite (PHP 8.2).
- `bin/lint` runs `php -l` (PHP 7.4) and PHPCS (WordPress standard).
